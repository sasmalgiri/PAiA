# Clinical content slot — HIPAA Boilerplate

This document is a content placeholder. Before publishing PAiA Therapy v1.0.0,
drop the following primary-source documents in this directory.

## Required (priority 1)

- **Notice of Privacy Practices (NPP)** template — HIPAA mandated;
  HHS provides model NPPs at https://www.hhs.gov/hipaa/for-professionals/privacy/guidance/model-notices-privacy-practices/
- **Business Associate Agreement (BAA)** template — HHS provides
  sample BAA provisions; many EHRs and SaaS vendors require BAA
  before processing PHI
- **Authorisation to Release Information (ROI)** template — must
  include the HIPAA core elements plus 42 CFR Part 2 elements when
  SUD treatment records are involved
- **42 CFR Part 2 quick-reference** — confidentiality of SUD treatment
  records is stricter than HIPAA; the SAMHSA guidance is public
- **Telehealth informed-consent template** — required in most
  jurisdictions; should cover platform security, recording, emergency
  procedures, identity verification

## Required (priority 1) — safety / mandated reporter

- **State-by-state mandated-reporter quick-reference** — Child Welfare
  Information Gateway (CWIG) publishes free state summaries; one
  document per state US, plus equivalent for UK / EU / IN
- **Duty-to-warn (Tarasoff and analogues) state-by-state** — varies
  significantly; some states have mandatory duty, others permissive,
  others none. Cite the relevant statute.
- **Elder-abuse mandated reporting** — Adult Protective Services
  contacts by state
- **988 Suicide & Crisis Lifeline** clinician quick-reference
- **National Domestic Violence Hotline** referral information for
  IPV-affected clients
- **Trevor Project** (1-866-488-7386) for LGBTQ+ youth

## Required (priority 1) — supervision and scope

- **Supervision agreement template** for pre-licensure supervisees
- **Group-practice supervisor contract** template
- **Scope-of-practice statement** for each common licence type:
  LMFT, LCSW, LMHC/LPC, PsyD, PhD, psychiatric NP, psychiatrist
- **Telehealth interstate practice** considerations (PSYPACT, Counselling
  Compact, Social Work Compact) — current status by state

## Recommended (priority 2)

- **Risk-mitigation documentation patterns** for safety-planning,
  hospital-handoff, no-show / discharge against medical advice
- **Insurance-credentialling-friendly intake form** — standardised
  fields most commercial payers accept
- **Sliding-scale fee agreement** template

## Quality checklist before publishing

- [ ] Templates reviewed by an attorney familiar with mental-health
      licensure in the relevant jurisdiction (NOT for legal advice but
      for template accuracy)
- [ ] All [BRACKET] placeholders clearly marked
- [ ] Each template has an attached "when to use this" guide
- [ ] State-by-state files use a consistent template so the persona
      can find the right one by state name
- [ ] Crisis hotline numbers are current (verify annually — 988 was
      introduced 2022)
